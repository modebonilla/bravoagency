# Sitio web Bravo Agency

Sitio estático (sin instalación). Funciona directo en GitHub Pages.

- `index.html` · página principal
- `servicios/` · una página por servicio
- `css/`, `js/`, `assets/` (las esculturas están en `assets/art/`)

## Contacto
El WhatsApp ya está configurado en `js/site.js` (`CONTACTO.whatsapp`). Para cambiarlo, edita ese número (solo dígitos con clave de país).

## Subir a GitHub
1. En el repositorio de somosbravoagency.com, NO borres el archivo `CNAME` (mantiene tu dominio).
2. Sube el contenido de esta carpeta (index.html, servicios, css, js, assets) y confirma los cambios.

## Tarjetas digitales (ocultas)
- Mode: somosbravoagency.com/tarjeta/direccion-general/
- Adimaira: somosbravoagency.com/tarjeta/direccion-operativa/
No aparecen en el menú ni en Google (noindex). Para poner una foto real en lugar de la escultura, guarda `assets/img/tarjeta/direccion-general.jpg` (o `direccion-operativa.jpg`) y vuelve a generar.
