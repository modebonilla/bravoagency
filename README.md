# Sitio web Bravo Agency

Sitio estático (sin instalación). Funciona directo en GitHub Pages.

- `index.html` · página principal
- `servicios/` · una página por servicio
- `css/`, `js/`, `assets/` (las esculturas están en `assets/art/`)

## Contacto
Abre `js/site.js` y escribe tu WhatsApp en `CONTACTO.whatsapp` (solo números con clave de país, ej. "522281234567").
Mientras esté vacío, todos los botones "Agenda tu cita" llevan al Instagram @somosbravoagency.

## Subir a GitHub
1. En el repositorio de somosbravoagency.com, NO borres el archivo `CNAME` (mantiene tu dominio).
2. Sube el contenido de esta carpeta (index.html, servicios, css, js, assets) y confirma los cambios.
